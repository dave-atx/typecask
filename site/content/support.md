## Something's wrong

Open an issue in [GitHub Issues](https://github.com/dave-atx/typecask/issues). For a bug, include
your device, your iOS version, and which font was involved. That's usually enough to reproduce it.

## A font is missing, or wrong

Ask for it in [GitHub Issues](https://github.com/dave-atx/typecask/issues) too. A wrong license, a
design style in the wrong collection or a preview that doesn't look right are all worth reporting.

A font only ships if a license can be found for it that allows redistribution. If a family you're
looking for isn't in the catalog, that's the most likely reason.

## Common questions

### A font says "Built into iOS" and won't install

iOS already ships a font under that same internal name, so registering another copy fails and every
app has the font anyway. Nothing is broken.

### I installed a font and can't find it in an app

Not every app can use installed fonts. Pages, Keynote, Numbers, Procreate and plenty of others can;
some apps use only their own bundled faces. Check
Settings&nbsp;&rsaquo;&nbsp;General&nbsp;&rsaquo;&nbsp;Fonts first: if it's listed there, the font
installed correctly.

### A font I installed disappeared

Fonts can be removed in Settings&nbsp;&rsaquo;&nbsp;General&nbsp;&rsaquo;&nbsp;Fonts, and Typecask
notices and shows the font as not installed again. Reinstalling it from the app brings it back.

### Does uninstalling Typecask remove my fonts?

The system keeps its own copy, so fonts stay installed through app updates and reinstalls. To remove
one, use Typecask or Settings before you delete the app.

### What are Nerd Fonts?

Fixed-width faces patched with an extra icon set, so a shell prompt, a status line or a file tree
renders the glyphs it expects. If you don't already know what they're for, you don't need them.

### What's this about Apple's fonts?

The app lists the fonts built into iOS and the extra ones
Settings&nbsp;&rsaquo;&nbsp;General&nbsp;&rsaquo;&nbsp;Fonts&nbsp;&rsaquo;&nbsp;More&nbsp;Fonts can
download, so you can see what you already have before installing anything. Typecask can't install
those; only Settings can make them available to every app.

## Requirements

iOS or iPadOS 27 or later, on iPhone or iPad.
