title: Font licenses
description: Every font in Typecask ships under its own license. How that works, and where to read each one.
---

Every font in Typecask belongs to its designers and comes with its own license. A font whose license
can't be found isn't in the catalog at all, in the app or on this site.

## Reading a font's license

Each font's page here has its full license text under **License**, and the app shows the same text on
each font's page. The whole set is also in the
[repository](https://github.com/dave-atx/typecask/tree/main/Licenses), one file per font.

The great majority are under the
[SIL Open Font License 1.1](https://openfontlicense.org), with the rest mostly Apache 2.0 or MIT.

## The previews on this site

The specimens on this site are the same preview files the app ships: each font's main face, cut down
to the sample text and renamed `TypecaskPreview-<font>`, which is roughly fifty glyphs. They're
there to show you the face, not to be used as webfonts — the lowercase alphabet and the digits are
most of what's in them. Each one stays under the license on its font's page.

If you want the real thing, every font's page links to where it came from.

## Typecask itself

The app's source code is under the [Apache License 2.0](https://github.com/dave-atx/typecask/blob/main/LICENSE).
That license covers the code and not the fonts.

Typecask isn't affiliated with Homebrew, Google or Apple.
