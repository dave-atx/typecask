# Glossary

## Axis

One of a variable font's sliders, like weight, width, or optical size. Some fonts add their own, like
Fraunces's Wonky or Shantell Sans's Bounce.

## Blackletter

The dense, angular style of medieval manuscripts and the first printed books, also called gothic or, in its
German form, Fraktur.

## Color font

A font whose letters carry their own colors, gradients, and shading, like Nabla.

## Condensed

A narrower version of a typeface, to fit more letters across a line.

## Contrast

The difference between a letter's thick and thin strokes. Bodoni has a lot; Futura has almost none.

## Counter

The space inside a letter, like the hole in an o or the bowl of an e.

## Display font

A font made for large sizes, like titles and posters, rather than paragraphs.

## Geometric

A sans serif built from circles, triangles, and squares, like Futura and Jost.

## Grotesque

The early sans serifs of the 19th and early 20th centuries, and the newer ones that follow them. American type
founders called them gothics.

## Humanist

A sans serif whose shapes follow writing with a pen, so it feels warmer and more open, like Open Sans and Fira
Sans.

## Kerning

Adjusting the space between particular pairs of letters, like A and V, so the spacing looks even.

## Ligature

Two or more characters drawn as one, like fi in a book, or -> and != in a coding font.

## Monospaced

Every character takes the same width, so text lines up in columns. Also called fixed width.

## Nerd Font

A coding font patched with thousands of icons for terminal prompts and code editors.

## Old-style

Serif type in the tradition of the Renaissance, like Garamond, with gentle contrast. Old-style figures sit like
lowercase letters, some rising above and some dropping below the line.

## OpenType features

Optional extras built into a font, like ligatures, slashed zeros, small caps, and alternate letters, which you
can turn on or off in Try It Out.

## Optical size

Versions of a typeface tuned for a size: sturdier for small text and more delicate for headlines. A variable
font with an optical size axis can switch on its own.

## Pixel font

A font drawn on a grid of square pixels, like the screen fonts of old computers and games.

## Sans serif

Type without serifs, like Helvetica and Inter.

## Serif

The small strokes at the ends of a letter's main strokes, and type that has them, like Garamond.

## Slab serif

A typeface with thick, blocky serifs, like Zilla Slab and Courier.

## Specimen

A sample that shows off a typeface, from a printer's sheet of type to a font's page in Typecask.

## Typeface

The design, where a font is the file that delivers it. Most people use the words interchangeably, and that's
fine.

## Variable font

One font file that holds a whole range of styles, set with sliders instead of picked from a few fixed weights.

## Weight

How thick a font's strokes are, from Thin or Hairline to Black.

## x-height

The height of lowercase letters like x, compared with the capitals. A tall x-height makes small text easier to
read.
